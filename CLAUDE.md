# RYSClaims

Земля команд для семьи RYS: приват, лимиты, прогрузка, защита. Заменяет FTB Chunks (вместе с RYSMap). modid `rysclaims`, пакет `works.repka.rysclaims`, NeoForge 1.21.1. Автор Дмитрий (MityaYS, RepkaWorks).

План и макеты: `../../_shared/_audit/map/plan.md` (разделы 6, 9.2, 10.5, 11, 12, этапы 13.4), факты разведки `R0-facts.md`, макеты `img/30`–`53`. Вид и тон семьи: `../RYSCore/CLAUDE.md`, раздел «Карта, приват и переезд (1.11)».

## Как работать с автором

* Общаться только по-русски. Прогресс списком, сделанное помечать ✅.
* Механики не выдумывать: CFR, исходники `../RYScope/research/mcsrc`, логи, тест в новом мире.
* Файлы не удалять, ненужное в `_stale`.
* Тексты для игроков черновые (`lang/ru_ru.json`), автор смотрит их до выпуска.

## Устройство

* `data/` без игры (кроме NBT): `ClaimData` вся земля в памяти и формат `rysclaims.dat`, `Claim`, `TeamLand` (добавки, права, переключатели, доверенные), `Rights`, `Limits`, `PlayerBonus`, `Settings` (снимок настроек), `Plots` (участки на лету), `Chunks` (упаковка как `ChunkPos.asLong`). `ClaimSavedData` это только обёртка `SavedData`.
* `server/ClaimService`: вся логика без игры (занять, освободить с отсчётом, оставить, прогрузить, права, машины, события команд). Измерение в нём строка id, время из `clock`. Клиенту не верим.
* `server/Loader` + `LoadPlan`: билеты `TicketController` `rysclaims:land` (сущность = UUID команды, ticking). Проверка при загрузке мира снимает лишние, `sync` раз в 10 секунд и по событиям сверяет поставленное с нужным.
* `server/ClaimsServer`: жизнь на сервере (ServerStarting, высокий приоритет, раньше переезда ядра в ServerStarted), тик, вход.
* `server/Protection`: защита событиями NeoForge, первым делом дешёвый выход (в измерении нет земли). Фейковый игрок судится `machineNames`, профилем и «Машины снаружи», его позиции не верим (R0, пункт 0.1). Порча блоков мобами судится только у монстров (`Enemy`): иначе на базе встали бы овцы, жители и големы.
* `server/Borders`: жидкость, огонь, молния через границу (зовут перехваты `mixin/`); сначала номера чанков, поиск только на границе.
* `server/DenyLog`: журнал отказов в памяти и файлах `world/rysclaims/log`, запись раз в минуту в своём потоке. `client/DenyFeedback` показывает замок и причину у прицела по пакету `Denied` и тост раз на землю.
* `net/ClaimsNet`: все пакеты (канал необязательный, сервер шлёт только клиенту с каналом): `Hello`, `Subscribe`, `Region`, `Diff`, `Access`, `Edit`, `EditResult`, `Keep`, `RightsEdit`, `Denied`. `net/RegionBytes`: регион 32×32 чанка байтом на чанк (номер в палитре до 63, биты прогрузки и «освобождается»), сжатие повторами, без игры.
* `server/ClaimSync`: подписки игроков (до 64 регионов, раз в секунду), правки чанков от `ClaimData.Changes` копятся до конца тика и уходят `Diff` подписчикам региона (больше 256 чанков региона уходят регионом целиком); `Hello` и `Access` сверяются раз в секунду и после `touch(команда)`, уходят при разнице. Обработчики пакетов и тик в главном потоке.
* `client/LandCache`: регионы подписки, команды из палитр, своя команда, итог правки; подписку собирает сам из `want` окна и карты плюс 3×3 вокруг игрока. `client/LandScreen`: окно земли (сетка, инструменты, панель лимитов, «Права»), выделение статическое до выхода из мира. `client/LandLayer`: слой, подсказка, пункт меню и строки под миникартой через `MapApi`. `client/ClaimsClient`: клавиши без назначения, кнопка «Земля» в панели семьи, тик кэша.
* `mixin/`: перехваты игры там, где событий нет (`rysclaims.mixins.json`, `defaultRequire = 1`: сломанный перехват роняет GameTest).
* `mixin/compat`: перехваты машин чужих модов (`@Pseudo`, строки целей, необязательный набор `rysclaims.compat.mixins.json`, `CompatPlugin` включает класс по префиксу имени, только если связка включена и мод загружен). Сигнатуры сверены `javap` с jar сервера RepYS. `compat/Links`: выключатели связок в `config/rysclaims-common.toml` `[links]` (читаются построчно до загрузки игры, выключенный перехват не применяется; файл создаёт `LinksConfig`), `compat/ApplyWatch` (расширение Mixin, держится последним, чтобы видеть поздние `@WrapOperation` MixinExtras) считает обработчики с местом вызова, `compat/LinkReport` при запуске сервера грузит цели без инициализации и пишет строку `[rysclaims] связки: встали …; не встали …; выключены …`. `server/Machines`: решение по месту блок-сущности и журнал.
* `compat/create/ContraptionPlace`: место постройки Create (блок управления из `assemble`, в NBT, иначе `anchor`); перехваты `mixin/compat/Create*`. Работник постройки (`MovementContext`) читается отражением в `Machines.contraption`, рука запоминается на свой тик (`Machines.actor`), шаг плуга помечается `Machines.vouch` (его фейковый игрок тогда не судится в `Protection.machine`).
* `compat/sable/SableLand`: позиция участка Sable в мировую и дом постройки (компаньон отражением, сначала проверка сетки `Chunks.sablePlot`); `SableAssembly` + `mixin/compat/SableAssemblyMixin`: фильтр блоков сборки и запись дома в `ClaimData.homes`.
* `data/Plot`, `data/Plots`: участки с номером и именем, одно правило пересчёта (`assign`) на слияние, разрез, перенос и старый файл; клиент считает тем же кодом «Соединит участки» и «Разделит участок».
* `client/InputGate`: гашение запрещённого нажатия до пакета (З6) по битам `Access`, только при свежей версии прав (`epoch` в `Hello`, `Access`, `Region`, `Diff`; растёт в `ClaimSync.accessChanged`).
* `server/Feed` (лента команды: участки, правки земли раз в 10 с), `server/Alerts` (попытки чужих: тост хозяевам, лента раз в минуту), `server/Membership` (вопрос о личной земле, «забрать свои чанки», предпросмотр слияния), `server/Admin` (окно оператора, правка чужой земли в режиме оператора), `server/Growth` (рост деревьев, мох, стебли).
* Перехваты З9 в `mixin/`: плиты, растяжка, кнопка (список сущностей), падающий блок, воронка, раздатчик, выбрасыватель, скалк.
* Окно земли `client/LandScreen`: «Сетка» (с выбором измерения), «Участки», «Права» (по ролям, доверенные, шесть переключателей), «Журнал», у оператора «Сервер» и «Команды». Пакеты окна: `LandState`, `LandEdit`, `LogRequest`/`LogPage`, `OwnerAlert`, `Question`/`Answer`, `AdminState`/`AdminEdit`.
* `server/Commands`: `/claims` (`server/TeamLookup`: команда по слову, точное имя команды раньше ника); `server/ServerConfig`: `config/rysclaims-server.toml`.
* `api/ClaimsApiImpl`: контракт ядра `claims.ClaimsApi`.
* `migrate/FtbWorld`, `FtbSettings`: чтение файлов FTB через `migrate.Snbt` ядра (своего читателя нет). `FtbClaims` считает перенос без игры, `ClaimsStep` это шаг `claims` ядра (порядок 30): кладёт базу одним сохранением, потом билеты; откат отказывает, если после переезда землю правили (счётчик `edits`).
* Права управления землёй (`rysclaims:claim`, `force`, `rights`) регистрируются в таблице прав RYSTeams (`TeamsApi.registerPermission`), второй таблицы ролей нет.

## Принятые решения

* Режим личных добавок `sum` складывает только добавки, а не полные лимиты, как FTB; `largest`, `owner`, `average` совпадают с FTB.
* Добавка за участника считается за каждого сверх первого.
* Лидеру своей земли можно всё; права монотонны: «все» ⊇ «союзники» ⊇ «команда»; гость в 0.1 получает столбец «Союзники».
* В `rights` хранятся только четыре действия доступа; права управления живут в RYSTeams (план, решение 18).
* `/claims admin bonus <игрок>` (личная добавка) добавлен сверх списка плана: без него личную добавку не выдать без квеста.
* `/claims loadmode online|always`: выбор команды в пределах `maxForceLoadMode` сервера (в плане это окно `42`).
* Переезд: «файла настроек ещё нет» из плана проверяется как «все значения по умолчанию» (`ServerConfig.untouched`): игра создаёт файл раньше шага.
* Команда FTB без пары остаётся за старым UUID, а её участники (`legacy.members`) остаются «своими» на её земле: иначе перенос отнял бы у них доступ. Управлять такой землёй может только оператор.
* Серверная команда FTB тоже остаётся за своим UUID с пометкой `ftb-server`; своей команды «Сервер» в 0.0.x нет.
* Земля FTB в измерении, где у нас приват закрыт (`neovitae:dungeon`), переносится: её не отнимаем, в отчёте строка.
* Жидкость FTB в RepYS через границу текла: перенос это сохраняет (`fluidsAcrossBorders = true`). Огонь FTB тоже не защищал, но у нас он не переходит и после переноса (план, таблица настроек).
* Снаряд Create Big Cannons без хозяина и без центра взрыва: землю команды не портит, кроме `ownerlessExplosions = always`.
* Машине с известным местом (блок-сущность) своя земля доступна на любом расстоянии: обе точки на земле одной команды, а «два чанка» плана защищали от недостоверной позиции фейкового игрока.
* Постройка Create судится по блоку управления, а не по `anchor`: у поршня `anchor` это конец штока, его можно завести на чужую землю. Хозяина у постройки нет. Разборка на закрытую землю роняет блоки предметами (путь Create для твёрдости -1).
* Пчела Productive Bees судится по своему улью, вспышка Botania без хозяина по блоку-источнику: их позиция летает.
* Окно правит права по праву `rysclaims:rights` из RYSTeams (по умолчанию только лидер), а не по жёсткому «только лидер» из раздела 6 плана: так велит критерий З4 («права правит тот, кому это разрешено в RYSTeams»).
* Скрытая земля («Землю видят») в 0.1 уходит всем клиентам как обычная, как у FTB с `public` (план 13.1, «Не входит»).
* `Hello` и `Access` не шлются по событиям, а сверяются раз в секунду с отправленным: дёшево (игроки × видимые команды) и не теряет ни одной перемены прав, ролей, союзов, доверенных, режима оператора.
* Окно земли показывает одно измерение, на котором открыто; подписка одна на игрока, на измерение последнего окна или карты.
* Участок без имени хранится пустым и показывается «Участок N»; отрезанная часть безымянного участка тоже безымянная, именного получает следующий номер («База 2», «База 3»).
* Плита, растяжка, кнопка: игрок без права «Двери» и его снаряд просто не считаются (без замка и журнала, иначе стояние на плите спамит отказами).
* Вагонетка с воронкой запоминает команду земли, где она первый раз заработала: события установки вагонетки нет.
* Лоза (`VineBlock`) через границу не закрыта: событие роста она не зовёт. Мох закрыт только от костной муки (радиус 3), трава нет.
* Вопрос о личной земле при вступлении это уведомление с кнопками, а не окно `45`; без ответа земля остаётся личной, вопрос приходит при входе. Отданная личная земля считается принесённой игроком (`by`), её можно забрать при уходе; забрать можно час.
* Землёй распавшейся команды (отсчёт 7 дней) управляет только оператор.
* Настройки сервера в окне сохраняются сразу, без «Сохранить» и «Вернуть как было» макета `51`; списки измерений и профилей правятся в файле.
* Оператор в режиме оператора на сетке освобождает и прогружает чужую землю от имени хозяев; занимает только для своей команды.
* Права по ролям: снятая роль снимает «Союзников» и «Всех», остальные роли остаются, как их было видно.
* Лента: попытки чужих раз в минуту, не больше трёх строк; правки земли раз в 10 секунд; машины только в журнале. Настройки журнала у команды: лента включена, тост выключен.
* Скрытая земля уходит чужому клиенту с UUID команды (нужен для гашения нажатия), без имени и цвета.
* Перехват машины отменяет метод работы в начале, а не вызов `setBlock`, если дроп собирается или предмет тратится раньше: иначе был бы дюп. Насос Oritech отсекается раньше: проверка источника перед осушением отвечает «воздух».

## Проверка

```bash
gradlew test                 # JUnit без игры: хранилище, лимиты, сервис, билеты, файлы FTB
gradlew runGameTestServer    # тестовый сервер без окна, куча 2 ГБ: команды, билеты, выход игрока, шаг переезда
```

* Настоящие файлы FTB RepYS берутся из `../../_shared/_saved/fixtures/ftb-2026-11-18` (вне git, свойство `-Pfixtures=`); без папки тест пропускается. В git лежат заготовки того же формата `src/test/resources/ftb`.
* GameTest живут в `src/gametest` и в jar не попадают. Перед запуском игры проверить свободную память. Перед каждым запуском старый мир `run-server/world` переносить в `_stale` (шаг переезда в нём уже сделан).
* `gradlew runGameTestServer -PcompatMods=C:/Projects/RepYS-Server/mods` подкладывает Cyclic, flib и Create (только чтение); тесты с игроком-заглушкой в таком запуске пропускаются (`CompatRuns`: Create шлёт пакеты всем игрокам, заглушка роняет сервер): так проверяется весь путь перехватов `mixin/compat`.
* Чанки тестов не тикают: поршень, молнию, огонь, ломатель Cyclic тест тикает сам (`triggerEvent`, `tick`), воду проверяет через `canSpreadTo`. Билет `setChunkForced` в далёкой земле запускает генерацию сотен чанков, не ставить. Тест кончается через `done(h)` (успех через 3 тика): иначе временные билеты синхронной загрузки мешают остановке.
* Остановка сервера GameTest иногда бесконечно крутится в выгрузке чанков (рабочие потоки стоят): сторож в `build.gradle` снимает процесс этого запуска через 30 секунд после строки итога, вердикт берётся из лога.
* Сборка требует соседний `../RYSCore` с выполненным `gradlew publish` (ядро 1.11.0).
