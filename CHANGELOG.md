# Изменения RYSClaims

## 0.0.6 (18.11.2026, Sable)

- Sable 2.0.6 через компаньон `SableCompanion.INSTANCE` отражением (без Sable ничего не грузится, жёсткой зависимости нет). Перед каждым решением защиты (блоки, взрывы, жидкость, огонь, машины, мобы) позиция в участке Sable переводится в мировую `projectOutOfSubLevel`; вне сетки участков отражение не зовётся.
- «Дом» постройки: перехват `SubLevelAssemblyHelper.assembleBlocks` пишет `UUID подуровня → команда земли якоря` в `rysclaims.dat` (поле `homes`, формат `v` прежний). Игрок команды-дома может всё на своей постройке, машина с профилем его участника тоже; остальным решает земля под постройкой. Отколовшаяся часть наследует дом родителя (`getSplitFromSubLevel`).
- Сборка не берёт блоки с земли другой команды, чем якорь: они остаются в мире, строка в лог.
- Чанк сетки участков Sable занять нельзя (пропуск «измерение без привата»).
- Не проверено в игре: Sable в тестовом сервере не поднимается (нужны Aeronautics, Veil, физика); случаи для ручной проверки на копии RepYS в CHANGELOG и плане С1. Разборка постройки на чужой земле (`SimAssemblyHelper.disassembleSubLevel`) не перехвачена.

## 0.0.5 (18.11.2026, машины мимо событий)

- Общие перехваты для фейковых игроков (R0, пункт 0.4): `ServerLevel.mayInteract` (плоскость разрушения AE2, Building Gadgets 2, насос Sophisticated) и `BlockItem.placeBlock` (плоскость формирования AE2, Integrated Tunnels). Судят профиль и список имён команды, позиции фейкового игрока не верят. Живого игрока `mayInteract` не трогает: игра спрашивает его перед любым правым кликом.
- Перехваты машин по месту блок-сущности (`mixin/compat`, `@Pseudo`, необязательный набор `rysclaims.compat.mixins.json`, включаются только при загруженном моде): Oritech (разрушитель, установщик, лазер, лесоруб), Cyclic (ломатель, установщик, установщик и сборщик жидкости, торфяная ферма), экскаватор Immersive Engineering, RFTools Builder (постройка, очистка, копия, перенос, обмен), ферма EnderIO (сбор урожая), духи Occultism (лесоруб и фермер, профиль хозяина духа), пространственный ввод-вывод AE2 (вся область, хозяин сети по `IPlayerRegistry`), взрыв реактора Draconic (по правилу взрыва без хозяина от центра реактора). Отмена стоит до сбора дропа и траты предмета: дюпа нет.
- Машине с известным местом своя земля доступна на любом расстоянии (`canMachine` с дальностью), через границу нельзя.
- Каждый отказ машине пишется в журнал с её именем (для блок-сущности тип и позиция).
- GameTest: `mayInteract` и `placeBlock` для фейковых игроков, место блок-сущности, ломатель Cyclic у границы (с `-PcompatMods=<папка модов>`, без неё тест пустой).
- Не покрыто: насос Oritech (жидкость добавляется в бак после осушения, отмена дала бы дюп), Productive Bees, линза бура Botania без хозяина, сборщик и сеялка Industrial Foregoing, руки и воронки Create (план, риск 3), бур, пила и каток Create (этап З5).

## 0.0.4 (18.11.2026, этап З2, часть 2)

- Вода и лава через границу земли (`FlowingFluidMixin`), огонь (`FireBlockMixin`: выгорание соседа и прыжок огня), огонь от молнии (`LightningBoltMixin`, у «Громовержца» ещё право его игрока), поджог лавой (`FluidPlaceBlockEvent`). На землю другой команды, в том числе со свободной, по умолчанию нельзя; настройки `[borders]`: `fluidsAcrossBorders`, `fireAcrossBorders`, `pistonsAcrossBorders`, `ownerlessExplosions` (`own`, `never`, `always`).
- Эндермен берёт блок только там, где мобам можно портить блоки (проверка настоящей клетки, а не места эндермена), ставит так же.
- Снаряды по блокам: `Projectile.mayInteract` судится правом «Строить» хозяина-игрока в клетке (горящая стрела и ТНТ, костёр, хорус, горшок, линза бура Botania), у монстра переключателем «Мобы портят блоки».
- Create Big Cannons: своё событие `ProjectileDamageEvent` (без жёсткой зависимости, класс ищется по имени): снаряд без хозяина не портит землю команды, кроме настройки `ownerlessExplosions = always`.
- Журнал отказов `world/rysclaims/log/<команда>.jsonl`: повторы склеиваются в памяти, запись раз в минуту в рабочем потоке, чистка старше `logDays` (7) раз в сутки. Машины пишутся с именем и UUID профиля. `/claims log [страница]`, `/claims admin for <команда> log`.
- Пакет `Denied` клиенту (необязательный канал): причина и имя хозяина (скрытая земля без имени). Клиент без канала получает строку над хотбаром, как раньше. Новые причины: жидкости, бой, гости не строят, свободная земля закрыта.
- Перенос с FTB: `flowing_fluid_protection`, `piston_protection`, `protect_unknown_explosions`, `max_prevented_log_age`. Огонь FTB в RepYS не защищал, у нас он через границу не переходит и после переноса (план, таблица настроек).
- GameTest: вода через границу и по своей земле, огонь жжёт свою доску и не трогает чужую, стрела игрока, журнал и склейка, молния «Громовержца»; поршень теперь проверяется в тикающем чанке.

## 0.0.3 (18.11.2026, этап З2, часть 1)

- Защита событиями NeoForge (план, раздел 11, строки 1–6, 8–18, 29): ломать, ставить, ЛКМ, правый клик по правилу «по умолчанию нельзя» (теги `rysclaims:use`, `free`, `build_items`), инструменты, вёдра и лодки по лучу в обеих позициях, сущности (монстры и мобы, что целятся в игрока, не защищены), бой игроков по настройке, вытаптывание, снаряды, взрывы (блоки и сущности по хозяину), порча мобами (только монстры), поршни через границу.
- Фейковые игроки: список имён команды, профиль участника, «Машины снаружи»; место фейкового игрока не учитывается (R0).
- Отказ пока строкой над хотбаром не чаще раза в секунду; замок у прицела придёт с клиентом (З4).
- GameTest: блок и сундук на чужой земле, взрыв без хозяина и свой взрыв, поршень через границу, машины по профилю и имени.
- Не сделано в этой части: перехваты жидкости, огня, молнии (строки 19–20), `FluidPlaceBlockEvent`, журнал отказов и `/claims log`, пакет `Denied`.

## 0.0.2 (18.11.2026, этап З3)

- Шаг переезда `claims` (порядок 30) в `migrate.Migrations` ядра: земля FTB Chunks в пустую базу, одним сохранением, затем билеты.
- Команды FTB с парой в RYSTeams сохраняют UUID; команда, чьи игроки уже в RYSTeams, отдаёт землю команде владельца; команда без пары остаётся за старым UUID, её участники остаются своими, управлять может только оператор; серверная команда FTB тоже.
- Права, переключатели, имена машин, видимость, союзники FTB в доверенные, личные добавки из личных файлов.
- Лимиты после переноса не меньше действующих в FTB и не меньше занятого: разница добавкой команде.
- Настройки FTB в `rysclaims-server.toml`, только если файл ещё не трогали.
- Откат отказывает, если после переезда землю правили. `/claims admin import ftb`, `/claims admin import undo` (уровень 4).
- Сверка «было в FTB, стало» в отчёте `[rys-migrate]`, расхождения строкой `MISMATCH`.
